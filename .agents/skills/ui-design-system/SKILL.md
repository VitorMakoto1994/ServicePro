# SKILL 07 — UI DESIGN SYSTEM

## Objetivo
Manter a identidade visual consistente, elegante, corporativa e livre de padrões genéricos ou clichês de inteligência artificial.

## Responsabilidades
* Preservar os tokens CSS centralizados no `:root` (cores, raios, sombras, tipografia).
* Padronizar espaçamentos consistentes (margins e paddings balanceados).
* Garantir hierarquia tipográfica clara (evitando negrito excessivo).
* Reutilizar componentes existentes: `.card-custom`, `.btn-premium`, `.btn-action`, `.table-custom`.
* Manter o padrão de Soft Tinted Badges translúcidos para status (sucesso, aviso, perigo, primário).
* Padronizar modais e formulários com focus rings sutis.
* Garantir apresentação de proposta comercial executiva no documento impresso/PDF (`#area-impressao`).

## Regra Fundamental
* **Não criar estilos isolados ou inline quando já existe componente ou classe equivalente no Design System.**
